# SMAPI 隔离技术样板（2026-10-30）

用户已批准最小试验。源码和运行方法在 [experiments/stardew-spike](../experiments/stardew-spike/README.md)。本轮只增加实验代码并更新文档；根入口仍是 Godot 0.18，未决定全量迁移。

## 实现范围与取舍

甲板复用原生 GameLocation、Farmer、背包、箱子与 LAN 会话。另一个原生地点承载横版潜水画面；主机统一处理扩建、船坐标、锚、泳动、氧气、矿点与威胁。初始甲板 12×8 格，每次扩建消耗 5 木；一个铜矿点，45 秒氧气，两人可交换角色或同时下潜。航行只验证坐标与海面表现，没有完整海图、岛间航线或海上碰撞。

**原生联机并不自动解决自定义交易。** 实测主机直接改客机 `Farmer.Items`，甲板已经扩建而客机仍有原来的木材；本机 1.6.15 的 `broadcastFarmerDeltas` 也只广播本地玩家 root。已改为主机验证并预约资源、持有者执行本地原生扣除／入包、回执后主机提交。订单及每人 `modData` 回执去重；未决订单与缺少持有者回执的已提交订单可重发。

自定义世界、库存订单与未决预约一起写入 Mod 存档；原生物品和个人回执随原生农夫保存。保存仍走原作过夜流程。没有移植 Godot 网络／库存框架，也没有新增第三方 Mod 框架依赖。

## 环境与隔离

目标是本机 Windows 原作 1.6.15、SMAPI 4.2.1、两个独立进程 LAN。运行文件复制到忽略的 `artifacts/stardew-spike/runtime`，Content 只读联接原游戏目录。bootstrap 在 SMAPI 启动前重定向原作三个路径方法和 SMAPI 的 DataPath/LogDir/SavesPath，并断言全部在独立 session 内。不通过该启动器时 Mod 不启用。

SMAPI 内包来自[官方 4.2.1 发行](https://github.com/Pathoschild/SMAPI/releases/tag/4.2.1)，下载 SHA256：`15E1EB1E3EDB405F56C44F9F66AD740305FF716498AD021BCEC569123E4F27D6`。没有把原作运行文件或素材加入源码分发，没有修改 Steam 启动设置。

测试使用受控原生菜单、原生寻路、一次右键事件和物品菜单点击；截图来自最终 backbuffer。它不等于物理键鼠回放或真人试玩。`host-a`、`guest-a` 含自动试验配置，不作为用户试玩目录。

## 结论和未验范围

结果支持继续评估 SMAPI 代码 Mod：原生生活系统、会话、人物、箱子和分地点结构可以复用，横版与扩建已有可运行接入。这不证明完整迁移比继续 Godot 更快；完整航行、原作日历／事件与生存节奏的协调、版本兼容和长期内容维护仍需评估。

同进程分屏未适配；跨电脑、真实键鼠全流程、真人观感、模组冲突、延迟丢包／进程崩溃时的物品边界仍未验。预约断线保存有纯规则证据，不能扩大成真实断网／崩溃验收。

美术是技术样板：原生陆地人物未中国化，海水／木板／敌人是程序占位，泳姿复用既有生成图。P2-08a“架空近代中国海港、民国劳动服饰参考”已确认，玩家＋严砧／沐桐配套样板仍未制作。
