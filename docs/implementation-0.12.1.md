## 已实现

- `scripts/world_state.gd`：放置/搬动返回可读原因；布尔查询、实时预览、主机执行共用判断。保留材料原子交换和通道规则，删除无调用的旧占格布尔包装；没有新增存档格式。
- `scripts/main.gd` / `scripts/game_hud.gd`：鼠标移动即更新原因卡；显示材料差额，支持O/P和左右键，取消不扣。建造中隐藏重复toast，沿用现有UI皮肤。

- `scripts/world_view.gd`：同源地板预览；落位轻尘、钩尾/接触水花、上下潜水花、加工就绪微光、入包图标与真实增量。镜头及实体比例不变，专用泳姿仍未实现。

## 限制

不等同于真人手感认可或跨电脑网络验证；旧快照超过MTU的警告仍存在。快照间完全发生并结束的瞬时动作可能不播放装饰效果，真实库存/成品标记仍为准。岛屿地理、存档和地图本轮不变；老设施素材、完整泳姿和P1/P2内容继续由TODO统一排期。

### 正常回放发现并补齐的P0-06问题

材料足够而12格满时，制作页原本仍开放制作，点击后才收到主机拒绝。现在Recipes.output_fits先模拟本人材料消耗后的格子，再判成品堆叠/空位；满包但正好用完一堆材料的配方仍可做。制作页明确显示“背包放不下”，主机继续使用原原子交换。没有自动整理或扩大背包。正常回放通过实际箱子存放干燥工具和额外战利品，改到造鱼叉之前；原失败证据保留。
