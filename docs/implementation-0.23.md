## 交付范围与设计边界

1. **`P2-44《一份用不上的救援记录》` 陆舟续篇长线（[脚本](narrative/yi-fen-yong-bu-shang-de-jiu-yuan-ji-lu.md)）**
   - 点亮西岸引航灯后，在岸边渔铺东侧空地右键查看只记险情的防水演练夹（`rescue_inspect`，`Vector2(1288, 300)`）→ 找港口救援员陆舟商议在平静好天组织镇民备航演练（让救援员的价值体现在避免事故，不靠反复风暴重演创伤，不新增遇险惩罚或削减现有救援机制）→ 找诊所苏芩核对防寒干毛巾与姜汤应急包 → 带 `rope × 2`、`wood × 2` 找护林员森柯做岸边快解系绳木桩与浮标练习架 → 跨夜完成演练后与陆舟及周潮写下“今日海面平静，全员平安收绳”的备航页，二选一定下岸边陈列（`平潮备航公告栏` / `岸边救生圈绳架`），获 `+40` 金币 + `meal × 2`，右键可随时执行 `rescue_style` 切换。

2. **`P2-45《名字各不相同的草》` 沐桐续篇长线（[脚本](narrative/ming-zi-ge-bu-xiang-tong-de-cao.md)）**
   - 承租东南荒院后，在苔瓦民居南侧开阔草坡右键查看写着不同俗名的植物写生夹（`herb_inspect`，`Vector2(1184, 1760)`）→ 找植物画师沐桐聊同一株海风耐盐草在农人、学堂与外岛的叫法分歧（与招牌画师阿沅的生活人物速写明确区分，绝不破坏或刷新玩家农田作物）→ 找镇公所学堂温知老师核对旧县志里的『海风车前』与田青常叫的『茶匙草』 → 带 `fiber × 2`、`veg × 1` 航行至风栖岛问林地精灵苔露听见的名字『听风耳』 → 跨夜等沐桐补完四时叶脉插画后，不强争唯一标准名，把三个名字与各自用途并列收入图鉴，二选一定下陈列（`多俗名田边木签`，荒院西门内侧同步立起手写木签 / `四时生长图鉴匣`，镇公所前厅木地板 `Vector2(252, 220)` 同步展陈翻页图鉴），获 `+40` 金币 + `salad × 2`，右键可随时执行 `herb_style` 切换。

3. **`P2-46《一张能用的误差表》` 顾星续篇长线（[脚本](narrative/yi-zhang-neng-yong-de-wu-cha-biao.md)）**
   - 点亮引航灯并结识领航员岑婆（或解锁海图）后，进入木匠工坊右侧白砖器械室右键查看写满红蓝批注的测潮铜尺台（`gauge_inspect`，`Vector2(608, 656)`）→ 听潮汐器械师顾星讲仪器理论读数与老船长经验在岬角回流处差半刻的苦恼（不把角色写成理性与非理性对立）→ 带 `ingot × 1`、`rope × 1` 航行至雾岬岛找海商白帆实测外海横风滞后 → 回潮芽镇公所请退休领航员岑婆与制图师陆遥并排核对风向余量 → 跨夜后顾星绘出标明适用海域与风偏区间的《潮芽港潮汐误差对照表》（如实保留海况余量，不变相做成 100% 锁物资或无风险外挂），二选一定下工坊陈列（`黄铜浮筒测潮仪` / `双栏潮汐余量板`，工坊室内与户外西廊同步呈现），获 `+45` 金币 + `cooked_fish × 2`，右键可随时执行 `gauge_style` 切换。

4. **`P2-47《被风认出来的旗》` 许棉续篇长线与木筏/海图实时同步（[脚本](narrative/bei-feng-ren-chu-lai-de-qi.md)）**
   - 制作船桨或罗盘后，进入潮芽超市裁缝角南侧木地板右键查看旧帆布风旗样篮（`pennant_inspect`，`Vector2(272, 736)`）→ 与裁缝许棉及沐桐聊耐盐风船旗与染布配色 → 带 `fiber × 3`、`rope × 1` 航行至雾岬岛请海商白帆指点远海最醒目的燕尾剪裁与活扣系法 → 带 `wood × 2` 找木匠贺木车制插在木筏右前角的防转旗杆座 → 跨夜试挂并被岸上熟人远远认出后，三选一定下木筏风旗纹样（`潮青双燕尾旗` / `暖赭归航三角旗` / `林翠风语长旒`），获 `+40` 金币 + `maki × 2` 并留下一块同纹样纪念布饰。
   - **纯外观与海图实时联动边界**：风旗造型纯属视觉与回访对白记忆，**不修改角色移速/体力/打捞半径等任何能力数值，不新增装备耐久损耗**；根据玩家当前真实扩建的 `deck_tiles` 自动定位木筏右前角旗杆（`LongStories.pennant_post`），无论在潮芽超市裁缝角还是在海上木筏船头右键均可随时执行 `pennant_style` 切换；打开 `M` 海图（`ChartPanel`）时，木筏实时坐标标记同步绘制对应配色的迎风小旗与图例说明。
   - `J` 手记实时汇总全部 **16 条已实装长篇故事**进度，相关居民均接入本轮长线推进与结局后的日常回访台词。
