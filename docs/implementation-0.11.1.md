## 实施顺序

1. 下载固定提交的原始图集、保留路径与哈希，查看真实像素；选择可衔接的地面、道路、水岸、围栏、建筑、树草、耕地和作物状态。
2. 复用现有IslandMap、Farming和CharacterArt。把图集区域、像素倍率、接地点集中登记；替换对应绘制路径，删除被替换的占位绘制，不重建地形/库存/联机框架，不改玩家存档或碰撞来迁就图像。
3. 荒院/镇前路段优先验收，共用地表能覆盖其他区域时一并接入；地形位置保持，地图显示同步。先比较现有32px人物与16×32候选的静态/行走/潜水及未来NPC成本，记录决定；有证据的基础步态问题本轮修复，缺少侧视游泳帧时继续明确缺口。
4. 运行比例/图集边界、受影响农耕和地图检查；960×600及1280×800实际输入截图，检查人物穿过树冠/围栏/建筑前后、工具点格与保存继续。完成正常入口完整回放及受影响本机双人验证，打包新版并更新启动入口。
