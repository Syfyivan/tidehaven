- 对应唯一排期：`docs/TODO.md` 的 `P2-12`（关联 `ROUTE-MAGIC`）。
- 脚本版本：`v1.0`（`0.20.0` 实装版，存入 `world_v18.json` 顶层 `chronicles.hai_lin_ju`）。
- 出场角色：温知（`wen_zhi` · 教师）、潮甲（`chao_jia` · 珊湾老海龟）、澜影（`lan_ying` · 回声海洞三层海灵）；关联风栖岛苔露（`tai_lu`）。

## 设计约束与旧档兼容

1. **不遗忘、不重学既有潮语与法术**：已解锁 `journal.tide_speech` 或已学会 `breath`（潮息）/ `rain`（唤雨）的旧档直接进入海中调查对话，不重置语言门槛、不扣回法术，也不跳过作物季节与过夜生长规则。
2. **具体误会与观察，不写空洞谜语**：将岸边异响与海龟绕路还原为“落锚与矿洞敲击回音让年轻海龟误以为礁石塌方，而澜影模仿船钟又让岸上误以为海雾警报”的双向生活误会。
3. **可见海岸信物且可切换**：完成后在潮芽岛西岸浅滩立起岸海约定的可见景致（『白石安澜界』叠石航标 `stone` 或『听潮海螺架』木架风铃 `chime`），可在浅滩右键菜单随时切换。

## 节点明细

### 阶段 0 → 1：西岸浅滩的潮水白石（`coast_inspect`）
- **进入条件**：已登上潮芽岛，`chronicles.hai_lin_ju.step == 0`。
- **触发地点**：潮芽岛西岸浅滩（`Vector2(216, 488)` 附近 110 单位内），右键菜单选择 `查看浅滩上排列整齐的白石与贝壳`。
- **即时反馈**：
  > 退潮后的浅滩上留着几枚被刻意排成弧线的白石，旁边礁石还有规律的轻敲水痕。去镇公所问问研究自然图鉴的温知老师吧（已记入J手记）。
- **状态改变**：`step = 1`，`day = data.day`。

### 阶段 1 → 2：温知 · 岸上与海里的两份记录
- **出场**：`wen_zhi`。
- **正文**：
  > 温知 · 海里也有邻居
  >
  > 你也注意到浅滩那排白石了？最近渔民说近岸海龟总故意绕远路，夜里又能听见像船钟一样的回音。我猜不是什么海怪作祟，倒像两边都在躲着对方。理解潮声之后，去珊湾潮岸找老海龟潮甲当面问问最稳妥——你准备先记哪一头？
- **回应**：
  - `0`：`先去珊湾找潮甲问清海龟绕路的原委。`
  - `1`：`记下敲击声的快慢节奏，顺便去海里核对声源。`
- **结果**：`step = 2`，记录 `choices[0]`，当前玩家对 `wen_zhi` 好感 `+15`。（注：若尚未完成三章共享主线解锁 `tide_speech`，手记与潮甲处会自然提示先跟随温知理解潮声；已解锁旧档直接对话。）

### 阶段 2 → 3：潮甲 · 被误认成塌方的回音（珊湾潮岸）
- **出场**：`chao_jia`（珊湾岛 `room == "island_reef"`，需 `data.journal.tide_speech == true`）。
- **正文**：
  > 潮甲 · 海里也有邻居
  >
  > 浅滩那几块白石是我推上去的。前些日子岸上修东西、海底又总传来闷闷的敲击声，年轻海龟以为礁洞要塌了，吓得宁可多游半天绕远路。其实有一半声音是从回声海洞最深处传出来的——你下潜到海洞三层找澜影问问，别让它再拿船钟声逗小家伙们了。
- **回应**：
  - `0`：`原来是回音闹的误会，我这就去海洞三层找澜影说清楚。`
  - `1`：`等问清声源，我们在西岸浅滩立个不惊扰你们的安静记号。`
- **结果**：`step = 3`，记录 `choices[1]`，当前玩家对 `chao_jia` 好感 `+15`。

### 阶段 3 → 4：澜影 · 学歪了的船钟声（回声海洞三层）
- **出场**：`lan_ying`（回声海洞 3 层 `room == "sea_3"`，需 `data.journal.tide_speech == true`）。
- **消耗**：`stone × 2`（用于在海洞口摆好定音石，分清回响）。
- **正文**：
  > 澜影 · 海里也有邻居
  >
  > 咦？岸上敲两下不是『打招呼』的意思吗？我听你们抛锚叮当响，就跟着敲石壁回礼，没想到把小海龟吓跑啦！给我两块结实的石料垫在水道边把回声收住吧——风栖岛的苔露还托潮水捎了片干叶给温知，过一夜你回镇公所和温知把岸海约定记进图鉴！
  >
  > 继续这段对话会交付：石料 ×2。
- **回应**：
  - `0`：`以后听到岸上轻敲木架三声，才是找你聊天的记号。`
  - `1`：`回声收稳就好，海龟们又能安心回浅滩晒太阳了。`
- **结果**：扣除 `stone × 2`，`step = 4`，`day = data.day`（需过一夜 `data.day >= rec.day + 1` 待潮水退定与整理记录），记录 `choices[2]`，当前玩家对 `lan_ying` 好感 `+15`。

### 阶段 4 → 5：温知 · 潮间邻居附录（跨夜定稿）
- **出场**：`wen_zhi`。
- **等待期表现**（`data.day < rec.day + 1`）：
  > 温知 · 海里也有邻居
  >
  > 我正在把潮甲的路线和澜影的回音记号誊进图鉴附录，苔露捎来的风栖岛干叶也压在书页里晒着。过一夜再来镇公所定下西岸浅滩的标记吧。
- **可完成表现**（`data.day >= rec.day + 1`）：
  > 温知 · 海里也有邻居
  >
  > 《潮间邻居附录》定稿啦！今早周潮说看见小海龟重新游回近岸晒背了，澜影也没再半夜乱学船钟。我们准备在西岸浅滩留一处长久信物，好让岸上的人和海里的邻居都认得——你喜欢哪一种？（完成后获得45金币与鲜蔬沙拉 ×2，请预留1格背包）
- **回应（二选一，决定初始 `style`）**：
  - `0`（`style = "stone"`）：`立一座『白石安澜界』，按潮甲认路的习惯叠起白石标。`
  - `1`（`style = "chime"`）：`挂一架『听潮海螺架』，海风吹过只有柔和低响。`
- **结果**：
  - 原子结算：`money += 45`，当前玩家背包获得 `salad × 2`；
  - `step = 5`，`choices[3] = reply`，`style` 设为 `"stone"` 或 `"chime"`；
  - 当前玩家对 `wen_zhi`、`chao_jia`、`lan_ying`、`tai_lu` 好感各 `+10`。
