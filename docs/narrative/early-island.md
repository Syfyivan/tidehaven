# 岛屿早期脚本：先把日子安顿下来

2026-10-29，脚本草案 v1，**未接入新对白/记忆**。对应既有 IS-01～06、P1-05、P2-03/05/07，以及后续 P2-09/10/14/22；不改变这些条目的实施状态。荒院租约、工具礼物、农事、小屋与店铺已有玩法，本稿为它们补人物对白与自然衔接，不再建一套强制新手任务。

## 流程与已有成果

建议玩家自然遇到的顺序是：码头问路 → 与镇长聊荒院 → 自愿承租/领取个人工具 → 自选一小片地 → 认识农人与木匠 → 自愿了解北街旧店 → 备料营业 → 居民回访。

这不是任务链锁。可以直接去找许岸、先逛森林、先看店或回筏生活；没认识田青不妨碍种地，没修屋不妨碍开店，没开店不妨碍出海。租店当前也不要求先租荒院，不新增此门槛。没有“清理10块杂物”“浇水6次”“必须见完镇民”。

所有节点默认由玩家主动交谈进入；不在走路时弹长对话，不拉镜头，不把NPC从日程中传送过来。出场地点用 `IslandTown.location` 和实际房间解析；下文的建筑名称只作空间提示。

## 共同结算与记忆规格

- 共享事实直接读取现有状态：租院、住房、租店、营业和共享主线。个人工具领取、短篇回应与好感仍归固定 `slot`。
- 本稿涉及“听过某段”“问过开店”“偏好先种地”等文字记忆，建议以稳定节点ID单独保存，**现有v16还没有这些字段**。未接入之前不能在发布记录声称NPC记得新偏好。
- 对话退出不等于选择“以后再说”，不会写记忆或扣款。事务成功才记录结果；NPC的自然答复和UI清楚的材料/金币反馈一起显示。
- 两人不需同场听同一句话。已经发生的公共成果可由另一人补问；首次租约、材料支付和一次工具领取仍由现有主机原子动作裁决。两人同时点同一共享事务，先成功者付费，后者只收到已经办理，不得双扣。
- 设计中的“偏好”只影响该玩家后续措辞，没有属性奖励/好感最优选项；随时可说“我现在改主意了”。重要共享决定另有明确确认，不把闲聊回答当签约。

## EI-00 · 靠岸后的一句话

**触发：** 玩家主动与陆遥交谈；未听过本节点时优先给简短自我介绍。也可从任意进度主动选“岛上怎么逛”。无租约/好感要求。

**出场：** 陆遥在自己真实路线位置；玩家无需站回码头。建议对话第一屏不超过两句。

陆遥：“你从海上过来的？我叫陆遥。镇公所在东街，买东西和歇脚都能往镇里找。”

| 回应 | 陆遥答复 | 结果 |
|---|---|---|
| “想找块能种东西的地方。” | “许岸正找人照料东南那座旧院子。地方挺大，你先去看看，再决定接不接。” | 记本人听过院子线索；不自动承租 |
| “先随便转转。” | “行。我最初认路也靠到处走。要问地方，再找我就是。” | 仅记相识；不生成追踪任务 |
| “北街那家店还开吗？” | “那间旧店现在可以谈租约。许岸管钥匙，陈鱼知道灶台什么毛病。” | 可以直接接EI-40信息，不要求先租院 |

**失败/推迟：** 直接关窗无状态变化；以后普通问路一直保留。初次交谈的每日好感沿用已有规则，不额外发一次见面奖。

**双人/旧档：** 各自知道什么分别记。旧档已有院或店时，替换“你先去看看”为“你们那座院/那间店往哪走，我也能给你指”；不能重新装作尚未出租。

## EI-10 · 这院子不急着收拾

**触发：** 主动与许岸谈院子；没有租约时显示承租选项。对应现有 `town_rent`。

**出场：** 许岸真实位置，工作事务遵守当前租约办理规则；不新增“必须在首次白天”的限制。

许岸：“东南那座院子空了好些时候，草都长到门边了。你要愿意照料，首期租金免了。”

玩家问“得收拾成什么样？”时，许岸：“能过你自己的日子就行。地那么大，用得上的地方先收拾，剩下的慢慢来。”

| 回应 | 答复与动作 | 记忆/分歧 |
|---|---|---|
| “好，我想住下来。” | 提示“承租荒院 · 首期免租 · 双人共享”，确认后调用现有租约动作 | 共享 `rented=true`；本人可记“打算住下” |
| “我多半还要在海上跑。” | “那也不碍事。回来有地方落脚，想种点什么再种。”仍允许选择同一承租动作 | 本人可记“海上为主”；不要求连续签到/收租 |
| “我先看看。” | “去吧。想好了再来，院子不会因为你晚一天开口就多算钱。” | 仅推迟；无租约、无扣款 |

**失败/推迟：** 不能因为选择住下立即搬动物资/清地/发工具；再次打开确认时重读共享租约。如果同伴刚承租，答“已经留给你们了”，不重复创建。

**双人/旧档：** 租约共享；私人定居倾向各自记录。旧档 `rented=true` 直接进入EI-11或普通谈院子，不用补写“首次签约者”这种档案中不存在的信息。

## EI-11 · 每人留一份

**触发：** 院子已租且 `claimed[slot]==false`，许岸提供现有 `town_claim`；可单独领取，不要求同伴在线。

许岸：“还有一份当季种子、锄头和水壶。给你留着呢，包里腾得下再拿。”

| 回应 | 处理 |
|---|---|
| “现在拿。” | 明示当季种子×6、锄头×1、水壶×1；现有逻辑先在背包副本完整放入，再一次标记已领取 |
| “我先整理一下。” | “好，东西在我这儿，不着急。”不标已领、不占别人份额 |
| “斧头也有吗？” | “这次备的是种地的工具。斧、镐和镰刀你可以自己做；严砧那里也有能买的工具。”不暗送额外斧头 |

成功后许岸：“种子别都急着撒下去。水壶还是空的，院里的淡水能装；你先挑一块顺手的地试试。”

**失败/推迟：** 满包、异常背包都不扣/不部分发放。显示“整份保留”，不让NPC祝贺已领。跨季后来领，以**领取日**的现有当季种子为准，不锁成初见那天的作物。

**双人/旧档：** 固定host/guest各一次；重连/断线不增加份额。旧档已领就不出现领取按钮，也不重新发放。未领的后加入玩家仍可拿本人那份。

## EI-20 · 一块够得着的地

**触发：** 主动找田青问种地；租院后可以出现“院子从哪儿开始”话题，但从未租院的新玩家也可先问。不是自动检查清理量的任务。

田青：“那院子大，光从一头走到另一头就够绕一会儿。先挑离水近、出门不绕路的地方，够你照看就行。”

| 回应 | 田青答复 | 影响 |
|---|---|---|
| “就先种几格。” | “挺好。每天走过去顺手看看，等熟了再添地。” | 私人“先试小片”偏好，仅用于措辞 |
| “我想留地方放别的。” | “留着。箱子、小屋、以后想做什么，总得有条能走的路。” | 不划永久施工禁区、不替玩家摆东西 |
| “工具怎么用？” | 进入可随时重问的工具说明：锄头点合法空地，持种子点已开垦单格，水壶点地，淡水补壶 | 沿用已有手持交互；不用开垦/播种/浇水Tab页 |
| “先出海，回来再说。” | “行，种子收好。要是换了季，回来先看看还能不能种。” | 无失败、无好感惩罚 |

**失败/推迟：** 说明页不消耗工具、水或种子。石块、树枝和荒草各由当前工具规则处理；对话不会代清。开垦失败仍用真实碰撞/边界原因，不以剧情放宽。

**双人/旧档：** 农田共享，偏好各自；已有农田只问“还想加一片吗”，不重置成荒地。不能凭某个玩家听了建议就宣称另一个玩家亲手种下第一格。

## EI-21 · 小屋先修到能住

**触发：** 找贺木问荒院小屋；修理仍需现有租院与合法位置。不是EI-20的完成条件。对应 P2-07已实现，后接P2-09/14。

未修时贺木：“旧屋能修。先把住的地方弄稳，想添房间，以后再量。”

| 回应 | 处理 |
|---|---|
| “要准备哪些材料？” | 服务区明确列木30、石12、纤维10，两夜完成；正文不再念一遍全部数字 |
| “材料齐了，动工吧。” | 使用现有 `town_home_repair`；执行时重新检查租约、背包、位置、是否已施工 |
| “我先住筏上。” | “也成。别为了修屋把种好的地全挖了，准备妥当再找我。”不扣好感、不登记失败 |

**失败/推迟：** 五处候选位置都被已有地块/箱子占用时，保留一切物件，准确说明需要空出一处。材料不足不部分消耗。已有工程只显示剩余游戏天数；不因聊天或现实过了两天就完工。

**双人/旧档：** 住房与施工共享，材料扣实际付款人背包。两人并发同工程只结算一次。旧档已修用“屋子住着怎么样”，已扩建不再兜售首次扩建；贺木住筏时在真实船屋找他，地图跟随真实位置。

## EI-30 · 镇民不是功能按钮

**触发：** 正常交谈。每次最多一件小事；不强制见满23人。引用 [characters.md](characters.md) 的稳定对白ID，后续接P2-05个人委托与P2-03短篇。

建议先选容易遇见的三种不同话题：林穗在意价签和口袋；汤禾在意失物和茶；周潮在意鱼讯和赤绳烤鱼。让人物互相提及，但不把每句都接成“请再去找另一个人”的跑腿。

| 当前事实 | 例句 | 不应发生 |
|---|---|---|
| 本人刚听完汤禾木屐故事 | “乔信那四只木屐终于凑成两双了。” | 给没听过的同伴播出“你替我问过的” |
| 小屋仍施工 | 贺木：“料已经收了，等屋里收拾妥当，再来挑放什么。” | 再扣一次材料，或说已经搬家 |
| 店已租但没营业记录 | 陈鱼：“案板在，食材得你自己备。想好哪晚开门了吗？” | 庆祝首晚收入，给虚构顾客评价 |
| 灯已修，另一玩家没参与 | 许岸：“码头灯已经亮了，你夜里回来能看见。” | 感谢这个玩家亲手交了材料 |

**失败/推迟：** 随时离开；不因只聊闲话不给商店/医疗服务。普通闲聊每日好感一次，不能每换一条候选句再领好感。

**双人/旧档：** 无“已听”字段的旧档默认未知，可重新听基础闲聊；所有世界事实仍从现有状态读取，不回滚。重连后不凭临时UI缓存认定人物已经记得新选择。

## EI-40 · 北街那盏晚灯

**触发：** 许岸处主动问旧店，或租院后普通交谈里出现一次简短提议；不要求修屋/收成/主线。当前 `town_shop` 条件保持不变。对应已实现P1-05，后续P2-10。

许岸：“你从海上来，打捞、潜水这些事比我熟。北街旧店正空着，想不想把带回来的鱼做成晚饭，在镇上卖？”

若没有可证明玩家潜水经历的标记，接入版改用更稳妥的首句：“你那条筏靠在码头？北街旧店正空着，想做鱼料理的话，可以看看。”不要凭开局身份宣称已经见过玩家熟练叉鱼。

| 回应 | 许岸答复 | 记忆/动作 |
|---|---|---|
| “听起来不错，先说说条件。” | “首期租金三十枚金币，再带十二块木板修整柜台。白天备料，傍晚开不开门你自己定。” | 仅显示现有报价；下一次明确确认才 `town_shop` |
| “先只做个小店。” | “能忙得过来就好。北街不缺大招牌，缺的是到饭点真能吃上的饭。” | 个人经营倾向；不自动租店 |
| “我还想多出海。” | “那就先出海。回来想试时再来，店铺不会按你离开几天罚钱。” | 暂缓提议、不反复每日催促；店仍可随时租 |
| “我对开店没兴趣。” | “知道了。以后改主意，你自己来问我。” | 记本人不主动提示；不封锁另一玩家询问 |

**失败/推迟：** 明确租店确认后按现有逻辑检查30共享金币和付款人12木板，一次成功。资料不足不扣费。关闭报价不是同意；问完条件不立刻走进营业。

**双人/旧档：** 单一租约共享。两人意见不同仍可各自生活，租店的共同成本在确认页明确展示；不得把个人“没兴趣”当全世界关店。已有店的旧档改用经营闲聊，不重租、不按“未听介绍”补收费。

## EI-41 · 第一晚之前

**触发：** 店已租，主动向陈鱼问备料或经营。不同问题可重问，不要求一次听完。

陈鱼：“先想好今天做哪几道，食材放到备料柜里。刚开门别把菜单写得比自己胳膊还长。”

| 回应 | 答复/界面 | 机制边界 |
|---|---|---|
| “怎么备料？” | 展示已有三道菜成本，提示在真实备料柜存入、案板制作、取餐 | 不复制一个剧情专用背包，不凭对白送鱼米 |
| “就我一个人，忙得过来吗？” | “先少接几桌的心思就好，备好菜再挂牌。忙不过来就收店，明晚还可以开。” | 当前顾客数与菜单按现有系统；若尚不能主动限桌，不给“设置桌数”按钮或声称已限桌 |
| “我们想一个做菜，一个上菜。” | “两张案板都能用。谁先空出手，谁去看看等餐的客人。” | 复用自由分工，不给两人永久绑定厨师/服务员职业 |
| “今天不开。” | “那就先把食材放好，门牌明天再翻。” | 不改变现有库存；无签到、无亏损惩罚 |

**失败/推迟：** 普通顾客可正常等待/离开，这是经营反馈，不能变成整个剧情永远失败。满包成品留案板；退出说明不取消伙伴正在做的菜。NPC不替玩家自动做菜/上菜。

**双人/旧档：** 非营业伙伴可去潜水，不强制同场。旧档已经经营过仍可重问机制；没有真实厨师雇佣前，陈鱼只能提供对白和自己的活动，不能声称会整晚留店代班。

## EI-50 · 上次开门以后

**触发：** 主动与陈鱼交谈，`restaurant.last`包含真实结算结果。当前结构为 `day/served/missed/revenue`；只在 `last.day == day - 1` 时说“昨晚”，否则说“上次”。每次结算的回访只优先一次，之后回基础闲聊。

| 真实结果 | 陈鱼正文 | 玩家回应与后续 |
|---|---|---|
| `served > 0`，`missed == 0` | “上次几桌都吃上了。忙完再看案板，跟开门前是两回事吧？” | “下次还这么做”／“想换点菜”，只记本人经营想法，不凭空解锁新菜 |
| `served > 0`，`missed > 0` | “有人吃上了，也有人没等住。是备料赶不上，还是上菜时手忙？” | “先多备一点”／“想和搭档再分分工”／“下次再试”；不假定每次都有搭档 |
| `served == 0` | “那回没把餐送出去。你要愿意，咱们从备料柜和案板顺一遍；今晚也可以先不开。” | “再问问做法”回EI-41／“先歇一晚”；无嘲讽、无永久封线 |

**小转折提案：** 后续P2-22可以由陈鱼在收工后承认自己只啃了余料开始，再问玩家愿不愿意一起吃。不是每次经营结算都触发心事，也不把未开发私人菜谱奖励塞入本节点。

**失败/推迟：** 无结算记录只说“想好哪晚试试了吗”，不编造评语。当前营业进行中不总结尚未结算收益。结算钱包上限沿用现有机制，回访不能补发第二份金币。

**双人/旧档：** 结果是共享店铺事实，不能把所有上菜功劳自动算给当前说话者；用“店里/那几桌”，不用“你送的”。缺少新“已听回访”字段时允许补听，不能重复发奖励。
