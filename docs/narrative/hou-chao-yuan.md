# P2-09 长线故事脚本：《候潮院》

编写日期：2026-11-26 · 脚本版本：v1 · 状态：**0.19 实装版**（对应唯一待办 [TODO.md](../TODO.md) `P2-09`）。

## 整体设计与边界

- **核心主题**：东南荒院并不是天降遗产，而是早年供误了潮期或避风船员歇脚晒网的“候潮院”。前照料者**岑婆**退休迁居外港后，院子渐渐荒芜。玩家通过现场发现门框刻痕、询问镇长许岸、与木匠贺木修整门廊/房屋取出旧住客账本、托邮差乔信寄信联系岑婆，收到回信后自行决定院子今后的生活定位。
- **独立版本化存储**：进度存储在 `world_v17.json` 的独立顶层字段 `chronicles.hou_chao_yuan`，绝不挤占或覆盖 `0.17` 固定 3 段的个人 `stories` 表，也不修改 `0.16` 共享主线 `journal.story_step`。
- **共享与个人归属**：候潮院本身是双人共享院落，因此阶段推进、门牌/门廊布置与金币奖励归共享世界（主机原子结算一次）；实际参与交谈/寄信的玩家的个人回应偏好与对许岸、贺木、乔信的好感增长归当前操作玩家，同伴可随时在 J 手记和居民处查看来龙去脉，不强制双人同屏对话。
- **旧档无损衔接**：旧档若早已承租荒院、甚至已修好或扩建小屋（`housing.level >= 1`），无需拆屋或重交修屋材料——阶段 2 找贺木时直接读取“修屋时替你们收妥的木匣账本”，不罚老存档重做。
- **候选角色边界**：岑婆（`P2-32`）在本条故事中通过乔信的跨海邮路亲笔回信与院务笔记出场，不在尚未制作完整人物日程前放置静态假立绘冒充实体 NPC 入驻。

## 节点详单

### HCY-00 · 门框上的旧潮痕（阶段 0 → 1）

- **进入条件**：已向镇长承租荒院（`island.homestead.rented == true`），`chronicles.hou_chao_yuan.step == 0`。
- **出场与触发**：玩家走到荒院西侧院门（`IslandMap.YARD_GATE` 64 单位内），右键菜单或空手交互出现 **「查看旧院门框刻痕」**（动作 `yard_inspect`）。
- **正文**：「院门木柱内侧留着几道深浅不一的横刻痕，旁边还有半个被海风磨淡的『候』字。不像量身高的记号，倒像在记某几场大潮——镇长许岸或许知道这座院子以前叫什么。」
- **结果**：`step = 1`，不消耗物品与体力；J 手记新增《候潮院》记录，提示有空去问问许岸。
- **推迟/并发**：不点查看不影响种地、修屋和放箱子；两人先后查看只推进一次，后来者收到已发现提示。

### HCY-01 · 许岸：不是谁留下的遗产（阶段 1 → 2）

- **进入条件**：`step == 1`，走近许岸（`xu_an`）交谈选择 **「长篇故事 · 《候潮院》」**。
- **正文**：
  > 许岸：「你看到门柱上那几道刻痕了？这座院子早年叫『候潮院』。那时候外海常有赶不上潮水、或是遇风耽搁的船员，镇上就在这儿留了几间通铺和晒网空地。后来航道改了，前头照看院子的岑婆也退休去了外港，院子才慢慢空下来。」
- **回应选择**：
  1. **「听起来这里以前很热闹。」**
     - 许岸答复：「热闹谈不上，多半是湿衣服和热汤味。贺木替人看过院里那间旧屋的梁木，说廊下还嵌着只防潮木匣，你们找他修屋或整修门廊时可以一并看看。」
  2. **「岑婆走的时候还留了话吗？」**
     - 许岸答复：「她说院子是给人住的，不是拿来供着的。对了，贺木上回检查旧屋门廊时提过梁下有只旧木匣，你去工坊或船屋找他聊聊。」
- **结果**：`step = 2`，记录回应 `0/1`，操作人 `xu_an` 好感 `+15`。
- **推迟/退出**：直接关闭窗口不推进、不扣物。

### HCY-02 · 贺木：廊下木匣与住客账本（阶段 2 → 3）

- **进入条件**：`step == 2`，走近贺木（`he_mu`，支持岛上工坊或已入住的筏上船屋 `raft_cabin`！）。
- **旧档与材料条件**：
  - 若荒院小屋已在施工或已修好（`housing.ready_day > 0 or housing.level >= 1`）：**免材料**（贺木修屋时已顺手把木匣取下收好）。
  - 若荒院小屋尚未动工（`housing.level == 0 and housing.ready_day == 0`）：交付 **`木板 × 6`** 稳固院门旧廊木，一并取出防潮木匣（不锁死 30 木修屋前置，玩家可自由先走剧情再修屋）。
- **正文**：
  - 已修屋/施工中：「修你们院里那间旧屋时，我在门廊梁下拆出这只桐油木匣，一直在手边给你留着。里面是一本旧住客账本，夹着几张海港热汤的做法，末页写着外港邮路的地址——署名是岑婆。」
  - 未修屋：「门廊那根横木确实松了，拿六块木板先替你顶稳。喏，梁下这只桐油木匣取出来了——里面是一本旧住客账本和几张热汤做法，末页留着岑婆在外港的通信地址。」
- **回应选择**：
  1. **「托乔信寄封信，告诉她院子又有人住了。」**
     - 贺木答复：「这主意踏实。乔信跑惯了外港邮袋，他准认得那个转交点。」
  2. **「先把账本收好，顺便寄信报个平安。」**
     - 贺木答复：「行，老木匠做的匣子还严实。去广场找乔信问问这趟邮船什么时候走吧。」
- **结果**：扣除 6 木板（仅当未修屋时；材料不足原样保留），`step = 3`，操作人 `he_mu` 好感 `+15`。

### HCY-03 · 乔信：寄往外港的近况信（阶段 3 → 4）

- **进入条件**：`step == 3`，走近邮差乔信（`qiao_xin`）。
- **材料条件**：交付 **`植物纤维 × 2`** 捆扎防潮信封。
- **正文**：
  > 乔信：「寄给岑婆？这个外港转交点我熟！白帆的顺风船明天一早就捎邮袋过去。信封用草绳封紧免得溅上盐水——你想在信里怎么跟她讲现在的院子？」
- **回应选择**：
  1. **「写我们正按自己的步调种地、过日子。」**
     - 乔信答复：「实在！岑婆最烦别人写客套话。信我装进头班邮袋了，过一夜回程船靠岸，再来我这儿看回信！」
  2. **「写院门和水道都收拾过了，随时欢迎旧友歇脚。」**
     - 乔信答复：「听着就敞亮！信封妥了，等过一夜邮袋带回来，你再来找我取信！」
- **结果**：扣除 `fiber × 2`，`step = 4`，记录寄出日 `day`，需经过至少 1 次真实过夜（`data.day >= sent_day + 1`），操作人 `qiao_xin` 好感 `+15`。

### HCY-04 · 回信与候潮院的新木牌（阶段 4 → 5 完结）

- **进入条件**：`step == 4` 且已过至少一夜（`data.day >= sent_day + 1`），走近乔信（或许岸）开启完结篇；若当天刚寄出则温和提示「邮船还在海上跑，过一夜再来听回音，没有期限」。
- **正文**：
  > 乔信：「回信到啦！岑婆字写得飞快，还随邮袋捎了一包干料。信上说：『我那双老腿不赶夜潮了，院子你们怎么顺手就怎么改，别替旧人守空房。门柱上的刻痕留着当个乐子，锅里有热饭比什么都强。』许岸也说，院门那块旧木牌正好按你们的心意重挂——你们想怎么安排？」
- **回应选择（决定可见院门风貌，后续可随时在院门切换）**：
  1. **「挂『候潮农庄』木牌，在门边添只歇脚竹篮。」**（`style = "farm"`）
     - 答复：「好嘞！院门换上了『候潮农庄』新牌，门边也摆好了竹编菜篮。岑婆附的《候潮院院务笔记》和两份热乎海港料理收好！」
  2. **「挂『候潮驿院』木牌，在门边留一盏夜归暖灯。」**（`style = "inn"`）
     - 答复：「妥当！院门换上了『候潮驿院』新牌，傍晚六点后门灯会亮起暖光。岑婆附的《候潮院院务笔记》和两份热乎海港料理收好！」
- **原子结算与可见变化**：
  - 检查共同钱袋上限与本人背包是否装得下 **`料理 (meal) × 2`**；若满包或钱袋满，**整步保留不扣不发**，提示先腾出 1 格背包再来拆包裹。
  - 成功后：`step = 5`，`style = "farm" | "inn"`，共同钱袋 **`+35 金币`**，本人背包获得 **`meal × 2`**，许岸/乔信好感再 **`+10`**。
  - **世界可见变化**：荒院西门（`IslandMap.YARD_GATE`）旧木牌更新为 `候潮农庄` 或 `候潮驿院`；`farm` 在门柱外侧安全草地绘制竹编菜篮，`inn` 在门柱旁绘制木架风灯（18:00 后亮起暖黄光晕），**零碰撞新增、零农田挤占**！
  - **随时可改布置**：完结后玩家在荒院西门右键菜单可随时点 **「切换候潮院门牌（农庄／驿院）」**（动作 `yard_style`），兑现“能调整的布置可后改”。
  - **日常回访联动**：许岸、贺木、乔信、陆遥的日常轮换池自动加入《候潮院》完结后的真实生活近况对白。
