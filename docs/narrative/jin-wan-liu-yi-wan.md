# P2-10《今晚留一碗》长篇节点脚本

- 对应唯一排期：`docs/TODO.md` 的 `P2-10`（关联 `ROUTE-SUSHI`）。
- 脚本版本：`v1.0`（`0.20.0` 实装版，存入 `world_v18.json` 顶层 `chronicles.liu_yi_wan`）。
- 出场角色：陈鱼（`chen_yu` · 厨师）、田青（`tian_qing` · 农人）、苏芩（`su_qin` · 医师）；关联提及林穗（`lin_sui`）、汤禾（`tang_he`）。

## 设计约束与旧档兼容

1. **完全自愿、无期限**：不强制租店或每晚营业，无倒计时惩罚；不因出海未钓到稀有鱼判失败，复用现有普通蔬菜（`veg`）与生鱼（`fish`），不暗自增加食材腐败或品质分级系统。
2. **旧档无缝续接**：若旧档已经完成过至少一次晚间营业结算（`not data.restaurant.last.is_empty()`），第 2 阶段找田青试配时令汤底**自动免去蔬菜 ×2 材料**，直接进入风味选择，不逼老店主重刷材料。
3. **双人共享与原子结算**：餐厅与长线进度全船共享（`chronicles.liu_yi_wan`），任一在线玩家均可推进；最终奖励（共享金币 `+40`、个人背包 `maki × 2` 寿司两份、对应角色本人好感）由主机一次原子结算，背包满或钱袋超限无损拦截。
4. **可见且可随时调整的店铺变化**：完成后北街旧店收银台旁与户外店门挂起对应席面暖帘/灯牌，可在收银台右键菜单随时在三种席面方向（『家常暖锅席』、`home` / 『时令鲜蔬席』、`season` / 『海港鲜鱼席』、`seafood`）间切换，不影响原有 3 道菜谱、16 格备料柜和正常顾客结算。

## 节点明细

### 阶段 0 → 1：收银台边的旧点菜单（`shop_inspect`）
- **进入条件**：已向镇长租下北街旧店（`data.restaurant.rented == true`），`chronicles.liu_yi_wan.step == 0`。
- **触发地点**：北街旧店室内（`room == "restaurant"`）收银台附近 96 单位内，右键菜单选择 `查看旧店墙角的点菜单底稿`。
- **即时反馈**：
  > 你在收银台抽屉底层翻出一叠旧粉笔水牌，边角反复写着同一行小字：『晚九点后，留一碗热汤』。去问问店里的厨师陈鱼吧（已记入J手记）。
- **状态改变**：`step = 1`，`day = data.day`。

### 阶段 1 → 2：陈鱼 · 一张够忙的菜单
- **出场**：`chen_yu`（北街旧店或下班后路线实际位置）。
- **正文**：
  > 陈鱼 · 今晚留一碗
  >
  > 你翻到那块旧水牌了？以前老酒馆还在的时候，总有人替晚下班的熟客托一句『留一碗』。现在店刚重新开张，我可不赞成一上来写满十二道菜——你是想开店，还是想把自己钉在案板边上？先说说，你打算怎么定咱们厨房的步调？
- **回应**：
  - `0`：`先把几道常备菜做稳，让人随时来都有热乎的。`
    - 即时答复：`对脾气！锅里常备着热汤，比花哨名字管用。田青那边有些长歪了不好上超市货架、下锅却清甜的当季菜，你去找她聊聊汤底吧。`
  - `1`：`跟着每天打上来的鱼和当季菜走，有什么鲜货做什么。`
    - 即时答复：`敞亮！海边小店就该吃这口鲜。田青地里常有样子歪一点但味道极好的当季菜，林穗嫌摆货架不好看，你去找田青问问能不能留给厨房。`
- **结果**：`step = 2`，记录 `choices[0]`，当前对话玩家对 `chen_yu` 好感 `+15`。

### 阶段 2 → 3：田青 · 歪萝卜也能上桌
- **出场**：`tian_qing`（农舍室内或实际日程位置）。
- **消耗**：`veg × 2`（若 `not data.restaurant.last.is_empty()` 已营业结算过则**免材料**）。
- **正文**：
  - 未营业过：
    > 田青 · 今晚留一碗
    >
    > 陈鱼让你来的？林穗挑货架总看个头齐不齐，可萝卜歪一点，切进热汤里谁分得出来？带两份普通蔬菜来，我教你把根茎甜味煨出来——顺便告诉你，以前总托人『晚九点留一碗』的其实是澡堂汤禾，他是替诊所晚下班的苏芩留的。
    >
    > 继续这段对话会交付：蔬菜 ×2（若旧店已营业结算过则免材料）。
  - 已营业过（免材料）：
    > 田青 · 今晚留一碗
    >
    > 听说你们店里已经开过火了，手脚真利索！林穗挑货架总看个头齐不齐，我这儿正好留了一篮甜根菜直接送去厨房。对了，以前总托人『晚九点留一碗』的其实是澡堂汤禾，替诊所晚下班的苏芩留的——你去诊所问问苏芩真正收工的钟点吧。
- **回应**：
  - `0`：`太好了，店里专门留一道不挑长相的时令热菜。`
  - `1`：`跟林穗分清用途，好看的摆货架，实在的进咱们锅里。`
- **结果**：扣除所需材料（若需），`step = 3`，记录 `choices[1]`，当前玩家对 `tian_qing` 好感 `+15`。

### 阶段 3 → 4：苏芩 · 不必等到半夜的晚饭
- **出场**：`su_qin`（诊所室内或实际日程位置）。
- **消耗**：`fish × 2`（用于试熬鲜鱼清汤底）。
- **正文**：
  > 苏芩 · 今晚留一碗
  >
  > 汤禾那个人，送茶嫌淡，留饭倒记了好几年。其实诊所没那么多半夜急症，我只是画窗边影子忘了看钟。带两条鲜鱼给陈鱼试锅底吧——跟他说不必替我熬到半夜，约个大家都能顺路坐下的普通傍晚，我们光明正大来吃一碗。
  >
  > 继续这段对话会交付：生鱼 ×2。
- **回应**：
  - `0`：`好，就约明晚收工时分，给熟客们留一桌热饭。`
  - `1`：`在柜台立块『留一碗』木牌，晚下班的人随时能热菜。`
- **结果**：扣除 `fish × 2`，`step = 4`，`day = data.day`（需经过至少一次真实过夜 `data.day >= rec.day + 1` 筹备晚席），记录 `choices[2]`，当前玩家对 `su_qin` 好感 `+15`。

### 阶段 4 → 5：陈鱼 · 今晚留一碗（跨夜筹备完成）
- **出场**：`chen_yu`。
- **等待期表现**（`data.day < rec.day + 1`）：
  > 陈鱼 · 今晚留一碗
  >
  > 高汤已经在小火上煨着了，汤禾、苏芩和田青都说明天傍晚过来。睡一觉过一夜，明天再来店里定下咱们招牌席面的路数吧；没有截止日期。
- **可完成表现**（`data.day >= rec.day + 1`）：
  > 陈鱼 · 今晚留一碗
  >
  > 昨晚那桌热汤吃得真舒坦！苏芩准点收工没让人等，林穗尝完田青的歪萝卜也没再挑刺，周潮还顺手送了一篓鲜货。往后店里就留这块『今晚留一碗』的席面牌——你想把咱们的招牌定成哪种风味？（完成后获得40金币与寿司 ×2，请预留1格背包）
- **回应（三选一，决定初始 `style`）**：
  - `0`（`style = "home"`）：`定为『家常暖锅席』，挂暖橙布帘、备粗陶汤碗。`
  - `1`（`style = "season"`）：`定为『时令鲜蔬席』，挂青竹菜牌、配田园竹篮。`
  - `2`（`style = "seafood"`）：`定为『海港鲜鱼席』，挂靛蓝鱼旗、摆木船刺身盘。`
- **结果**：
  - 原子校验钱袋与 1 格背包空间后：`money += 40`，当前玩家背包获得 `maki × 2`；
  - `step = 5`，`choices[3] = reply`，`style` 设为对应席面；
  - 当前玩家对 `chen_yu`、`tian_qing`、`su_qin` 好感各 `+10`。
