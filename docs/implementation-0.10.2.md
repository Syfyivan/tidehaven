# 0.10.2 UI样板实施计划

2026-10-12：用户已同意星露谷式生活像素风的制作标准。本轮交付可试玩的探索HUD、背包/箱子、制作界面；不迁移引擎、不改变玩法或引入外部依赖。当前文档修改继续保留。

实施结果：0.10.2本地可玩版已打包，启动入口已更新；379项相关回归、49项图形输入/状态/截图检查、本机双人34/24/6项和364.441秒完整正常输入回放通过。实际图见art-direction.md，验证与限制见verification.md。风格方向获认可，具体画面待真人反馈；未提交/推送。

1. 先跑现有背包、视口、实际工具输入检查，建立改版前基线；保存当前UI截图作为对照。
2. 扩展既有SVG界面皮肤和UIStyle，统一暖纸/木边、青绿选中态、数量、字阶与间距；保留真实文字和控件。用九宫格保持边角尺寸，避免整图拉伸。移除这些页面重复的外观覆盖，不新增UI框架。
3. 调整HUD信息层次，重排背包/箱子和制作详情；保留12/16格、左右键拆分、实际物品农事、配方分类、联机菜单时间及存档语义。
4. 用真实渲染检查正常/悬停/选中/禁用、空格/满包、长中文名、缺材料和窗口缩放。完成聚焦回归、本机联机及最终打包版正常入口→收集/制作→保存继续验证，再更新启动入口。
5. 将实际图、验证范围与剩余缺口同步美术规范、来源、复用记录和TODO。技术验收与用户审美认可分开，跨场景环境和完整人物动作仍未完成。

简化范围：共用一套皮肤和控件状态，复用既有交互与自动回放；不增加每页独立美术系统，不复制背包或制作规则。

## 验证中发现的回放问题

第一轮正常开局在划桨断言停止：收集期间木筏已漂至潮芽岛边界，回放固定向北点击时撞岸；船桨实际扣除2体力，岸边碰撞清除了推力。`artifacts/playthrough-20261012-003428-034/report.json`保留失败状态，`artifacts/paddle-probe.log`用该状态复现了实际点击与碰撞。没有修改航行规则。

修正回放通过已有Archipelago位置计算远离岛体的海面方向，仍要求实际点击、目标方向位移和恰好2体力扣除；ui_skin_checks新增贴岸向外划行回归。整段正常开局需用重新打包的版本重跑，不能以这个位置夹具代替。
