## 本轮发现并修正的问题

1. 客机加入初帧尚无housing时，绘制直接访问键报错。改为初始快照安全读取；新ENet实际加入/换装/修屋/登岛/独立续档复验。
2. 船屋配方需要四种材料，旧制作页只建三行；增加一行并按四材料压紧高度，分隔线/图标同步，两窗口实际点击62项通过。船屋归探索页末尾，避免挤乱原生存制作列表。
3. 新岛原本只支持上下文采集，手持斧/镰/锄点击没有走room_mine。接入统一手持路径；木材复用原生挥斧/合法走近，四种工具实际完成后才结算。
4. 跨日保存恢复温室/盆栽growth、餐厅账目/库存时JSON浮点与内存整数不一致。恢复入口规范化类型，58天/14次经营/每日存读278项通过，保护暖棚跨季且未浇水不增长。
5. 修屋材料不足时先改site会造成隐藏状态变化。改为本地候选选址，支付成功后才写入；钱袋满的委托/故事保持物品和待领奖励。
6. 历史测试固定v14、旧版禁止新岛、设施元数据未覆盖船屋，均与本轮范围不符；更新迁移/登记断言。矿口224宽含两侧各32岩边，保留原160碰撞基础，不为矩形测试改变地图。
7. 新网络探针初版主客外观夹具不一致、连续RPC快于80ms限制、登新岛漏id导致失败。改为双方同一档案、等待真实快照确认并留输入间隔、明确目标岛；没有放宽生产RPC限制。失败目录完整保留。
8. 最终交互复核发现普通左键候选可能包含收起家具/海上委托服务。明确排除这些动作，只允许右键菜单选择；家中实物与容器UI另外做实际放置/拆分/取出/回收检查。不会改变旧海上打捞、工具和制作规则。
