# 0.10 岛屿开荒与小镇

用户澄清：岛上是大片尚未开垦的土地，并有小镇、不同职业的居民、森林、矿洞、湖河溪流与小水泊、澡堂、超市、诊所。地块数量与生活内容同样重要，不能以大而稀疏的地图代替探索。

## 实施与保留计划

1. 保留现有逐格锄地/播种/浇水/按天成熟、工具耗时采集、自由分工和方向钩。备份源码、测试、工具、文档与配置到 artifacts/before-0.10-20261005-114759。
2. 岛上默认无已开垦农田。增加疏密变化的荒草、枯枝和石块；先清理占用格，再用锄头开垦，已开垦格不再长回采集节点。
3. 沿近港道路落地小镇、建筑碰撞和门前服务、不同姓名职业的居民。复用个人背包、共享金币、附近菜单和主机裁决；不引入新的经济/对话框架或依赖。
4. 湖、河流、溪流、水泊与桥用同一几何定义控制画面、行走、补水与地图。矿洞入口明确未开放，洞内层级不冒充已完成。
5. 新版入口与存档独立于旧版。保护旧农田/库存；测试新地形冲突迁移。完成相关规则、真实输入/显示、正常入口保存继续和本机联机检查后再切换启动入口。

当前不把完整室内、关系/好感、剧情、全村日程、矿洞层级、饭店经营标为完成。唯一持续待办为 TODO.md。

## 本轮文件分工

- `scripts/island_map.gd`：保留历史地形校验与节点坐标，增加镇建筑、水系、桥梁和成团荒地物资。
- `scripts/island_town.gd`：居民/营业时间、个人库存和共享币交易、诊疗/泡澡，采用现有主机规则。
- `scripts/farming.gd`、`island_state.gd`、`island_activity.gd`：清理阻碍提示、旧农田迁移与历史采集安全取消。
- `scripts/world_state.gd`、`main.gd`：动作/RPC、个人对话暂停、v10读写与旧档保护、淡水岸钓。
- `scripts/world_view.gd`、`island_atlas.gd`、`town_dialogue.gd`、`context_actions.gd`：镇场景、地标/水系、可关闭对话与可滚动服务菜单。
- 地图/服务/旧档/图形/真实ENet和正常入口回放检查同步，详见verification.md。没有安装新依赖，没有提交或远程发布。

现阶段建筑可识别、有碰撞和门前服务，但尚不能进入室内。八名居民复用原有授权的两张人物图做服色/配饰区分，尚非八套独立美术。完整关系、委托故事、真实通勤路线和矿洞层级保留待办。
