# 0.11.2 人物、荒草与可见通行边界

2026-10-12用户明确否定当前人物，要求头身衔接自然、体型不臃肿；院子不应整块铺泥土。道路问题已确认是能够走到水面、建筑或视觉上不通的位置，草地和空地仍应能自由走动。本次反馈覆盖此前“保留人物”的选择。

实施顺序：

1. 保留当前0.11.1包和用户存档。先复现池塘路径未标桥、道路整段漏画、建筑精灵底座与碰撞位置不同的问题，增加针对性回归；不扩大为地形/存档重建。
2. 接入同一归档来源的完整16×32人物与独立居民表，统一四向帧映射、2倍像素标尺、脚点、名字/工具位置。移除旧角色改色和临时帽子绘制；现有角色文件保留但不再用于本批角色。专用游泳帧不冒充完成。
3. 荒院恢复草地底色，真实纤维资源改成草丛，割草后消失、锄地后才出现土穴。保留已有地块与资源ID/掉落，不生成赠送田。
4. 水面/道路/桥梁由同一地形定义决定；道路分段验证，水面交叉只通过可见桥通行，陆地脚部碰撞考虑脚掌宽度。建筑显示底座对齐现有碰撞范围，屋顶只遮挡、不得让身体进入实体立面。同步岛图。
5. 检查两种窗口、主客角色/居民四向/工具选择、院内清草锄地、池岸/桥/围栏/建筑真实输入和保存继续；受影响本机双人及最终Windows包正常流程验证通过后更新入口、规范、TODO与来源清单。

复用IslandMap、WorldState、Farming、CharacterArt与IslandArt，不新增依赖。旧图集原文件不修改；素材清理只删除被替代的运行时绘制分支，不删用户文件或历史证据。审美反馈不以测试数量代替。
