## 交付范围与设计边界

1. **5 位海上伙伴原创世界像素精灵补齐（`OceanResidentArt` 零第三方角色图依赖）**
   - 由 `tools/build-021-art.py` 绘制与 `0.19` 海洋肖像一一对应的原创二值透明双帧精灵表（`assets/characters/ocean/*.png`）：
     - `bai_fan.png`（`32×32`，单帧 `16×32 → 32×64`）：银发立领深青航海大衣配木扣内衫，海风轻摆下摆与额发。
     - `chi_sheng.png`（`32×32`，单帧 `16×32 → 32×64`）：暗红海盗包头巾（侧结随风摆动）、独眼罩与红敞领海盗外套。
     - `chao_jia.png`（`64×32`，单帧 `32×32 → 64×64`）：金赭色温和老海龟头颈与苔绿六角背甲、浅金腹甲，带轻微呼吸点头动态。
     - `tai_lu.png`（`32×16`，单帧 `16×16 → 32×32`）：青瓷薄荷圆润露珠精灵，顶芽绿叶与粉颊叶足（同时修正 `world_view.gd` 旧灰度图染色乘算，呈现真实原色）。
     - `lan_ying.png`（`64×32`，单帧 `32×32 → 64×64`）：深青潮洞海灵，双侧弯曲荧光海藻鳍翼、翡绿发光眼、额角藤壶与浪沫下摆。

2. **`P2-14《开门能看见海》` 木匠与船屋长线（[脚本](narrative/kai-men-neng-kan-jian-hai.md)）**
   - 修好荒院小屋（`housing.level >= 1`）或贺木已入住筏上船屋（`housing.carpenter == true`）后，在木匠工坊门前右键查看船窗草图（`workshop_inspect`）→ 找贺木聊船上百叶窗与短航（已住筏旧档直接补看初住船屋听浪往事，不把贺木搬回岸上重走邀请）→ 找铁匠严砧打制防盐窗轴（需 `wood × 4`、`ingot × 1`；**已住筏旧档自动免材料**）→ 带 `rope × 1` 航行至雾岬岛请海商白帆实测风口活结风钩 → 跨夜等贺木回岸探望严砧与顾星后，二选一定下临海工作角（`迎风敞窗工角` / `防潮风灯工角`），获 `+40` 金币 + `meal × 2`。
   - 完工后木匠工坊门廊外及已放置的筏上船屋外侧同步呈现百叶木窗架或黄铜防风暖灯（18:00 后亮起暖光），工坊门前右键可随时执行 `workshop_style` 切换。

3. **`P2-20《歪萝卜也能上桌》` 田园与餐厅时令合作长线（[脚本](narrative/wai-luo-bo-ye-neng-shang-zhuo.md)）**
   - 承租荒院后在苔瓦民居门前右键查看分叉菜筐（`farm_inspect`）→ 听田青讲分叉甜根菜被超市挑剩的苦恼 → 找超市林穗了解零售货架隔夜损耗的实在账（不把林穗写成反派）→ 带普通 `veg × 3` 与森林 `mushroom × 1` 找北街厨师陈鱼试做时令小钵（不强加隐藏作物品质/腐败系统，不垄断玩家收成）→ 跨夜听熟客好评后二选一定下民居门前陈列（`田间直供菜篓` / `时令腌菜陶坛`），获 `+35` 金币 + `salad × 2`，门前右键可执行 `farm_style` 切换。

4. **`P2-28《留一把椅子》` 海盗补还旧账与店门规矩长线（[脚本](narrative/liu-yi-ba-yi-zi.md)）**
   - 承租北街旧店后，在珊湾岛赤绳营地旁右键查看铁锅边的旧店传单（`pirate_inspect`）→ 赤绳嘴硬想上岸吃热饭 → 回岸边渔铺找周潮核实真相（确认三年前大雾天赤绳确曾割走周潮外礁浮标的两条备用粗缆与黄铜网坠，**绝不洗白成误会**）→ 带 `rope × 2`、`scrap × 2` 回珊湾让赤绳当场认账并连夜亲手编好双股粗缆送还渔铺栈桥 → 跨夜后周潮确认“东西两清、交情另算”，由店主玩家与陈鱼三选一立下店外规矩（`廊下矮凳席` / `侧窗外带台` / `港规留步牌`），获 `+45` 金币 + `cooked_fish × 2`，寿司屋门外西侧呈现对应实景并可右键执行 `pirate_style` 调整。

5. **`P2-29《今年的沙滩》` 珊湾海龟迁徙与护沙长线（[脚本](narrative/jin-nian-de-sha-tan.md)）**
   - 解锁潮语（`journal.tide_speech == true`）后，在珊湾岛老海龟潮甲东北侧干沙滩右键查看折返爬痕（`reef_inspect`）→ 潮甲说明季风杂物引发新老海龟路线争执（不做任务也绝无动物伤亡惩罚）→ 回岸边渔铺找救援员陆舟核对巡海册漂流带记录 → 带 `fiber × 3` 赴风栖岛请林地精灵苔露挽制顺风护沙草束 → 跨夜退潮沙暖后二选一定下珊湾安排（`向阳歇沙坪` / `慢行浮木标`），获 `+40` 金币 + `sashimi × 2`，珊湾沙滩右键可随时执行 `reef_style` 切换。
   - `J` 手记实时汇总全部 8 条已实装长篇进度，`ResidentDialogue` 同步新增各相关居民回访对白。
