# 0.8 实施与清理计划

2026-10-05：当前运行窗口确认是 0.6；源码/启动入口为 0.7。保留运行中的窗口和历史存档，本轮输出独立 0.8。

先备份 scripts/tests/tools/docs 与配置；以现有背包、制作、导航、RPC 和素材目录为基础，不加依赖。

1. 删除按漂流物 ID 锁定的打捞和鼠标高亮。方向在出手时固定，主机模拟飞行、碰撞、浮动、收回；满包和双人不能吞物或重复奖励。
2. 水下木材/矿石/沉箱改耗时操作，移动和右键可取消；斧头/镐加速。鱼叉按方向发射，鱼移动可以躲开，成功才入包。
3. 船锚统一由 G 操作：抛锚停船、起锚出发。岸边另用绳子系泊/解缆，不能把两种停船物资混用，也不能遗留同伴。
4. 随身罗盘解锁完整群岛海图和远程航标；没有罗盘只显示附近海域，首岛仍能目视抵达。
5. 增加行为回归后替换旧自动锁定入口；验证真实键鼠、有限背包、主机裁决、存读与旧档迁移。历史自动锁定测试需要按新规则更新，不能保留测试专用快速领奖通道。

本轮不扩展敌人、洞穴、工作台、饭店和故事线。交付前记录测试覆盖与手感、跨电脑联机的验证缺口。
