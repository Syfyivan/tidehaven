# 0.9 岛屿采集与逐格农耕

目标：岛上砍树/枝、割纤维、采石/矿和挖埋藏物需要对应工具及时间；逐格开垦、播种、用有限水量的水壶浇水，四季及不同生长天数真正参与玩法。大岛使用固定分页镜头及海域→岛屿→分区地图，保留双方自由分工。

清理/替换计划：备份 `artifacts/before-0.9-20261005-103902/`；以回归锁定原打捞、背包、航行、存档合同。删除岛上瞬时领取和共享单块按秒成熟逻辑，复用个人背包/手工配方/主机裁决/活动进度/跨天机制；岛上状态改稀疏 depleted 与 plots。v9读取v8及以前时迁移既有岛上收获/作物，暂未完成的动作取消，原档保留。筏上原种植盆本轮保留旧合同并明确仍待升级，不能宣称全游戏种田重做完成。

实现分工：主代理负责世界接线、采集活动、输入与物品图标/提示、迁移和可玩版；独立子任务负责 farming 规则/物品配方、地图/分页渲染/二级图。最多两名子代理，只有主代理串行运行引擎。

首版数值：28天一季；春萝卜4天、夏秋玉米7天、秋南瓜10天、冬雪根6天，具体配方/产出以farming.gd为真。浇水过夜才成长；未浇不成长，跨季露天不适季作物枯萎。单格小暖棚需制作并放置，豁免季节但仍需浇水。水壶20次容量，淡水点补充。工具收集按节点时间完成，移动/右键取消，满包不吞物，双人不能重复领。

岛屿实际坐标14336×6528像素，32像素一格（448×204格），分16×12个896×544视页、六大分区。地图大小并不代表每格都有独特手工内容；分区使用可复现资源/地貌分布和稀疏持久化。与姜岛的精确可走面积尚未逐图核对，不标“已证明超过姜岛”。完整故事、洞穴及岛上营业仍是已有后续待办。

验证：农耕季节/灌溉/成熟/满包/并发/存读、耗时工具采集、跨页移动/坐标输入、二级地图、旧档副本；真实客户端与新游戏正常入口→航行登岛→制作工具→采集/挖掘→逐格播种浇水→过夜/收获→保存继续分别验证。测试夹具、规则检查和自然成长回放明确区分。

参考规则来源：[Crops](https://wiki.stardewvalley.net/Crops)、[Watering Cans](https://wiki.stardewvalley.net/Watering_Cans)、[Ginger Island](https://wiki.stardewvalley.net/Ginger_Island)。姜岛原作全年可种，本游戏按用户要求采用露天季节限制。仅参考机制，不复制原游戏素材或代码。
