# 海上伙伴对话肖像来源记录（0.19，2026-11-26）

为补齐 0.18 遗留的 5 位海上伙伴（白帆 `bai_fan`、赤绳 `chi_sheng`、潮甲 `chao_jia`、苔露 `tai_lu`、澜影 `lan_ying`）对话肖像缺口，使用内置图像生成代理（`image-generator`）按各自已有世界精灵身份与设定绘制像素半身原稿，再经 `tools/build-019-art.py` 洪泛去品红底、去边缘色溢并按 64×64 网格采样为严格二值透明（alpha=0 或 255）的 `64×64` PNG。

- 运行时由 `scripts/portrait_art.gd` 统一以 `Rect2(0, 0, 64, 64)` → UI `128×128`（2 倍最近邻）接入 `TownDialogue`，与 18 位镇民共用同一底部对话布局与原生边框。
- 逐文件尺寸与 SHA256 见同目录 `manifest.json`。未引用第三方商业游戏肖像图或新增外部依赖；用户审美仍待试玩确认。
