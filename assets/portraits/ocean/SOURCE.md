# 海上与海岸伙伴对话肖像来源记录（0.19—0.22，2026-11-26）

使用内置图像生成代理（`image-generator`）按各自世界精灵身份与设定绘制像素半身原稿，再经 `tools/build-019-art.py` 与 `tools/build-022-art.py` 洪泛去底、去边缘色溢并按 64×64 网格采样为严格二值透明（`alpha == 0` 或 `alpha == 255`）的 `64×64` PNG：
- **0.19 首组 5 位海上伙伴**：白帆 `bai_fan`、赤绳 `chi_sheng`、潮甲 `chao_jia`、苔露 `tai_lu`、澜影 `lan_ying`。
- **0.22 新增 2 位海中与海岸角色（P2-34 / P2-35）**：
  - `mi_luo.png`（人鱼修补匠米洛：海珠白肤与青绿鳞纹、珊瑚蹼耳、深青波浪海藻发、额戴黄铜钟表放大镜与斜跨齿轮工具带）
  - `san_jin.png`（爱占秤盘的海豹三斤：圆润银褐斑点海豹、乌亮圆眼与胡须、前鳍搭在盛着扇贝壳的旧黄铜鱼秤盘边）

运行时由 `scripts/portrait_art.gd` 统一以 `Rect2(0, 0, 64, 64)` → UI `128×128`（2 倍最近邻）接入 `TownDialogue`，逐文件尺寸与 SHA256 见同目录 `manifest.json`。
