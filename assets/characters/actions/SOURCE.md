# 持斧人物动作来源（2026-10-16）

两张为内置imagegen生成的完整角色动作图，参考当前已授权接入的Alex/Leah完整人物外形。不是从原作抽取的工具动画，也没有拼接原作头和另一套身体。原文件完整复制，SHA256见manifest.json。

候选选择：host来自exec-3ea42ce7-0773-4508-a9a6-c1c0755b6887.png；guest来自exec-14f73a77-ede6-47ae-ad32-fb88baa5cd46.png。较早男角色候选因背向下劈位置错误淘汰。文件名candidate保留来源阶段信息，不代表原始大图可直接发布为像素素材。

生成约束记录：1536×1024透明背景，6列×4行，每格256×256；行顺序朝下、朝右、朝上、朝左。六阶段为握柄准备、举斧、蓄势、下劈、接触、收势；双手握住柄，工具随手和身体协同，面向树；保持同一完整头身、衣服、四向身份与固定脚点。男角色棕发绿上衣蓝裤，女角色橙色辫发绿上衣棕裤。无文字、格线、地面、发光描边。以上是约束摘要，未伪称逐字原始调用提示。

原生成图存在非整数像素和半透明晕边。ChoppingArt在运行时最近邻至44逻辑像素宽，alpha>=0.96才保留，按2倍世界单位显示；人物可见身高与原角色约56单位校准。朝下劈斧两帧裁切高度296以容纳斧刃；朝右相邻行两帧去掉顶部35源像素，固定脚点仍为(22,42)。这是已登记的动作画布例外，不改变CharacterArt静态16×32原图或人物碰撞。

逻辑参考只用FarmerSprite的分阶段工具动作思路；实际节奏来自本项目主机activity.duration/remaining。没有移植原作角色渲染器、换装系统或逐击奖励。

验证证据与用户观感分别记录在docs/implementation-0.13.1.md和docs/art-direction.md。原PNG不被测试或转换脚本覆盖。
