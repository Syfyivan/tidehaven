## 开始试玩

以下直接运行方式适用于本机已有的 Windows 安装包；从 GitHub 克隆请先完成下方“获取源码”步骤。

双击 **开始游戏.cmd**，或运行 `build/Tidehaven-0.10.1.exe`，无需安装编辑器。也可在 Windows 开始菜单搜索“潮间小屋”。**F11** 切换全屏；窗口可自由调整大小。

选择「新游戏」体验从小木筏开始的生存流程。选择「继续游戏」会保留旧世界的物资和设施，不会强制重置成新开局；没有存档时该按钮不可用。请先在旧窗口保存退出，再用新版继续。

双人需要相同版本：进入「联机游戏」，房主「创建房间」，朋友输入房主可达的 IP 加入。使用 UDP 24872，适合同一局域网或已配置好的虚拟局域网；没有公网中继、账号或 Steam 邀请。房主退出会保存并关闭房间，之后可继续单人。

0.5 重做海面动感与常驻界面：漂流物在同向海流中错落移动，间隔、速度和水面起伏各不相同；木筏与甲板物件一同轻轻浮动，镜头固定。去掉常驻米黄厚边框，压缩状态与工具栏。海底新增可搜索的沉箱，继续复用已有物资宝箱、库存和开箱规则。

0.5.1 去除场景固定留边与不同比例窗口的黑条，海面延伸到窗口边缘，世界和界面各自保持等比缩放。双人人物换用 Pipoya 原版 32 像素角色，区分蓝衣与红衣，接入四方向行走帧；水下采用同一人物加潜水面镜、气瓶的简化表现。完整游泳动作仍待后续制作。

0.6 更换木板、塑料、废金属等 11 种物资原图，统一场景、背包和制作图标；背包显示用途、来源与剩余格子，制作显示已有/所需/缺少数量。人物保持上一版。木筏现在随流真实航行，能制作船桨转向、简易锚停船。

0.7 统一处理全部物资和设施的深黑轮廓，包括木桶、箱子/开箱、睡袋/床、种植箱各阶段及建造预览；睡袋独立绘制，人物保留。新增海图和真实可达的潮芽岛，支持采集、岸钓、露天采矿、一块可播种浇水的农地。左键/O主操作、右键/P收取或附近菜单，M海图。

## 海图与首座岛

按 **M** 查看“我的木筏”、大海与四座岛。**潮芽岛**可以到达，另外三座只标出规划轮廓，显示“尚未开放”，不能传送或设置航标。选航标只提供方向；需要自己划桨。

1. 在 C 手工制作船桨和简易锚，按3选择船桨，左键或O朝指针方向划。右上会显示潮芽岛方向/距离。
2. 靠近岛西侧的停泊点，按G抛锚；走到筏边按P/右键，点击“登上潮芽岛”。
3. C手工做齐岛上工具，按1后靠近点击目标采集；初始工具石料可先在水下慢慢采得。清理杂物后从底栏选锄头开垦一格、选一粒种子播种、选水壶浇水；完成浇水后在港口营地结束当天。西岸钓点携带钓竿，用左键/O抛竿、右键/P收竿。
4. 回西侧码头，从附近菜单返回自己的木筏。两人可以一人留筏、一人登岛，也可以一起登岛；所有在线玩家返筏后才能起锚。

岛上资源按种类隔1～7日再生；已开垦的田格不再刷资源。水壶、独立田地、当前季节和采集状态随世界保存。M依次查看岛屿总览、分区及视野页，地图标出营地、码头与淡水。岛屿面积和独特内容密度分开推进，尚未验证比姜岛实际可走面积更大。完整饭店、可进入的温室建筑、木匠招募与住房仍在项目待办。

## 从小木筏开始

1. **WASD / 方向键**移动。默认拿打捞钩，左键 / O 朝海面抛出，右键 / P 收回；钩尖沿途可带上多件漂流物，到手时放入背包。木桶会带来多种材料。漂流物持续再生。
2. **C 制作**：两片棕榈叶搓一条绳；两份塑料做杯子。先攒木板、塑料和绳，做简易净水器。
3. 制作设施后，鼠标移到绿色格子，左键放置；右键 / Esc 取消。材料在实际成功放置时扣除。地板接在已有木筏旁，可逐格扩建。
4. 在筏边按 **P / 右键** 选择舀海水，走近净水器加入海水和一块木板。等 12 秒，收取淡水饮用；喝完留下空杯。
5. 制作钓竿，走到筏边按 **2** 选竿、点击水面抛竿；约 5 秒后按右键 / P 收竿。带着生鱼、木板走近自己建的烤架，等 10 秒收烤鱼。
6. 左键点击附近目标或按 **O** 执行主要动作；**右键 / P** 展开附近操作菜单，可直接点击休息、结束今天、搬动等条目。原 **E / Tab / F** 仍兼容。吃喝也出现在附近互动里，**R** 吃熟食；底栏中的熟食 / 淡水可点击使用。
7. 继续建储物木箱、种植箱。种子可从漂流桶和稀有宝箱取得；筏上种植箱暂沿用约65秒的旧生长规则，岛上农田则逐格按季节和天数生长。蔬菜配鱼可在烤架做料理。
8. 做简易锚并按 **G** 抛锚后，筏边可以下潜。水下按4用鱼叉朝方向捕鱼，按1靠近资源开始耗时采集，左上浮标旁返航。靠近睡袋休息，或准备结束今天；全体在线玩家准备才跨天。

饱食和饮水缓慢下降，低于 15 时行动和休息恢复会变慢。水下耗氧，缺氧只让该潜水员返航并损失自己的生鱼。镜头保持稳定；仅木筏及其甲板物件有轻微二维浮动。

## 漂流、划桨与抛锚

没有工具时木筏随海流漂行，物资以相对速度掠过；右上角可查看航行状态。镜头跟着木筏保持平稳，尾流和物资方向反映移动。

- **C → 船桨**：3 木板 + 2 塑料 + 1 绳，成品放自己的背包。按 **3**，点击海面朝该方向划桨，每划消耗 2 体力。停划后逐渐回到随流漂行。
- **C → 简易锚**：3 木板 + 2 废金属 + 1 绳。甲板按 **G** 抛锚，锚从背包移到筏上；再次按 G 收回，需有背包空间。简易锚可重复使用。
- **下潜前须抛锚**；有人还在水下或岛上时不能起锚。停船后仍随海浪轻轻起伏。
- 两人可以各自带桨共同操船；锚属于共用木筏。当前有一座可航行抵达、停泊和登岸的潮芽岛；帆和发动机留待后续。

## 下潜、熔炼与装备

先把吃喝安顿好并抛锚，再从筏边下潜。水下有灰褐石料和带锈色矿脉的石块，靠近按 **E** 采集；附近多个动作时用 **Tab** 切换。每处石料给 2 份、矿石给 1 份，消耗 4 体力；满包会保留矿点，全体过夜后刷新。鱼、木材与矿点都是两人共享的采集点。海床上的两处沉箱靠近后按 E 搜索，可取出物资宝箱；按 B 选中宝箱打开。满包时沉箱保留原状，已经搜索过的沉箱保持打开，过夜才补充。两个人搜索同一处只会得到一份。

按 **C → 探索与升级**，用 **6 石料 + 2 废金属 + 4 木板** 建熔炉。靠近熔炉用 **1 矿石 + 1 木板** 炼制，等 **15 秒** 领取一块金属锭。满包时成品留在炉里；一个人可以下海采矿，另一个在甲板炼制。

| 装备 | 材料 | 放在个人背包里的效果 |
|---|---|---|
| 脚蹼 | 2 金属锭 + 4 塑料 + 1 绳 | 游泳速度提高 30% |
| 强化打捞钩 | 2 金属锭 + 2 绳 | 打捞距离增加，收钩更快；仍按 1 使用 |

装备放进木箱后不再生效，同类多件不叠加。每个人分别准备自己的装备。

## 重新布置甲板

靠近设施或木箱，按 **P / 右键** 并点击“搬动”，再左键点空甲板格；右键或 Esc 取消。箱子槽位、物品、设施成品和正在进行的加工计时全部保留。搬移无需额外材料，也不会返还材料。

位置必须在身边且不堵住通路；伙伴先搬动了同一设施时会取消你的旧预览。移动床会取消休息和过夜准备。地板目前不能搬动或拆除。

## 背包与存放

**B** 打开背包。每人 12 格，同类每格 20 件；每个木箱 16 格。个人背包独立，甲板木箱共享。靠近箱子再打开背包即可手动存取。

- 左键选整堆，再点目标格移动、合并或交换。
- 右键选半堆；已有选择时，右键目标格放入 1 件。
- 选中背包物品后可「丢弃」，再次确认才扣除显示数量；可用右键先选半堆。
- 「整理」合并同类物品。「尽量存入」填充身边箱子，装不下的留在背包。
- 甲板制作和设施先使用自己的背包，再使用甲板箱中材料；岛上手工只用自己的背包；不会拿伙伴背包。成品进入操作人的背包。
- 满包不会吞掉漂流物、加工成品或渔获；整理后再领取。

钓鱼每竿独立：45% 鱼、45% 木材、10% 物资宝箱。宝箱在 B 界面选中后打开，得到 3 木材、2 种子和 1 鱼；空间不足时整个开箱不发生。离开筏边或岛上岸钓点会取消本次垂钓。

## 暂停与保存

Esc 打开菜单。单人菜单、背包、制作、海图与附近操作菜单暂停世界；多人个人菜单不暂停，房主可从菜单暂停全房。休息与结束今天分别操作，人员进出会取消睡觉准备。

日结、每分钟、房主保存退出、客人离开时保存。存档在 `%APPDATA%\TidehavenPrototype`，新版文件 `world_v9.json` 与 `.bak`。只有新版文件及备份都不存在时，才只读导入 v8（其次 v7、v6、v5、v4、v3、v2、v1），另存 v9。旧文件不改动。新建世界先归档当前 v9 主文件和备份；主文件损坏或缺失可恢复备份。

v5及更早旧档导入后保持停泊，防止原来水下的角色被迫追船；全员返航后可收回一个兼容锚再出航。旧物资与设施不重置。

## 美术和当前边界

人物使用 [PIPOYA FREE RPG Character Sprites 32x32](https://pipoya.itch.io/pipoya-free-rpg-character-sprites-32x32)，允许用于个人和商业游戏，禁止把素材本身再次分发或出售。物件、植物继续使用 [Kenney Tiny Town](https://kenney.nl/assets/tiny-town)、[Tiny Dungeon](https://kenney.nl/assets/tiny-dungeon)、[Tiny Farm](https://kenney.nl/assets/tiny-farm) 的 CC0 图集。物资新增 [Yapi 100 Assorted Items](https://yapilol.itch.io/100-assorted-items-16x16-pixel) 的 11 张 CC0 原图。海面、交互效果、UI 和少量物品图标由项目代码定义。人物原图未改像素，来源与授权记录见 [assets/sources.md](assets/sources.md)。

这是可玩的早期版本，尚不是《星露谷》级别的完整美术和内容量。目前一片浅海、一座六分区可登陆岛屿、四种岛上作物、二十三个配方；筏上种植箱仍为旧版共享作物/按秒成长，尚未升级成岛上日历农田；还没有完整温室建筑、工具耐久、战斗、餐厅经营、其他岛屿开放、剧情、音效或拆除回收。新世界不预送订单站，旧存档保留原订单与扩建进度。双人仍为房主 + 一个固定伙伴槽，适合可信朋友。

后续成长路线是海上维持吃喝和扩建 → 航行遇岛/补给 → 岛上种植、供货与饭店经营；细节与优先级只在项目待办维护，首岛基础采集/农地/岸钓已实现，完整饭店和木匠入住尚未实现。

## 获取源码

仓库：[Syfyivan/tidehaven](https://github.com/Syfyivan/tidehaven)，当前为私有仓库，需要仓库访问权限。

```powershell
git clone https://github.com/Syfyivan/tidehaven.git
cd tidehaven
```

安装 Godot 4.7.1。人物素材作者禁止原始素材再分发，因此 Git 不包含两张 PIPOYA 人物 PNG。请从 [PIPOYA 官方页面](https://pipoya.itch.io/pipoya-free-rpg-character-sprites-32x32) 免费下载 `PIPOYA FREE RPG Character Sprites 32x32.zip`，然后在项目目录执行（替换为实际下载路径）：

```powershell
.\tools\setup-characters.ps1 -ArchivePath 'C:\Downloads\PIPOYA FREE RPG Character Sprites 32x32.zip'
```

## 开发与验证

Godot 4.7.1 / GDScript，无新增插件依赖。`tools/check.ps1` 运行规则、库存、生存、探索升级、持久化与本机双进程联机检查；`tools/check-progression-network.ps1` 单独验证操船、收放锚、采矿、熔炼和搬移的真实 RPC。`tools/playthrough.ps1` 在图形进程中通过正常键鼠事件验证导出版本，从空背包跑采集、制作、操船收放锚、净水、烹饪、采矿炼锭、装备、搬移、保存继续，最长 8 分钟。`tools/playthrough.ps1 -Island` 从空背包自制箱子和农具，划到岛上开田，经过四个实际浇水夜晚后收获并保存继续；`tools/check-island-network.ps1` 覆盖岛上合作。均使用隔离存档。

规则与配方：`scripts/world_state.gd`、`inventory.gd`、`recipes.gd`。显示：`world_view.gd`、`art_catalog.gd`、`game_hud.gd`。界面和网络：`main.gd`、`ui_style.gd`、`crafting_panel.gd`、`inventory_panel.gd`。`tests/ui_gallery.gd` 只生成受控状态的实际渲染截图，不证明正常游戏进度。具体证据与尚未覆盖的验证在 `docs/verification.md`。
